## 3. 已实现部分的技术契约（**不要重做，直接复用**）

### 3.1 Rust：目录浏览命令（`src-tauri/src/commands/fs.rs`）
```rust
#[derive(Serialize)] #[serde(rename_all="camelCase")]
pub struct DirEntry { name: String, path: String, is_dir: bool, size: u64, modified_at: u64, ext: String }

#[tauri::command] pub async fn list_directory(path: String, show_hidden: bool) -> Result<Vec<DirEntry>, String>
#[tauri::command] pub async fn parent_dir_of(path: String) -> Result<Option<String>, String>
```
- 目录优先 + 名称小写排序；`show_hidden=false` 跳过 `.` 开头；传入文件路径时改列其所在目录；权限错误返回中文 Err
- 前端调用：`invoke<DirEntry[]>("list_directory", { path, showHidden })`、`invoke<string|null>("parent_dir_of", { path })`
