## 为什么是 MasterEdit

> 从专注 Markdown 的 **MasterMD** 进化为全能轻快的 **MasterEdit**：
> 告别动辄几百 MB 的重型 IDE 与臃肿阅读器，用不到 **7 MB** 的体积，把 **「Markdown 写作导出、PDF 阅读批注、代码函数级导览、表格查看编辑」** 四件事做到极致顺手。

| 维度 | MasterEdit | 常见 Electron 编辑器 / 重型阅读器 |
| --- | --- | --- |
| 安装包体积 | **约 6.5 MB** | 80 – 300 MB |
| 冷启动速度 | **约 0.3 秒** | 2 – 6 秒 |
| 空闲内存占用 | **约 30 MB** | 200 – 600 MB |
| 多格式一体 | **Markdown + PDF 批注 + 代码导览 + 表格** | 需分别安装多个软件 |
| 双栏对照 | **每栏独立缩放、独立导航历史、支持同文档对照** | 全局缩放联动或不支持同文件分栏 |
| 更新方式 | **应用内一键校验并自更新（双节点容灾）** | 手动下载重装 |

## 核心特性

### 📊 办公表格查看与编辑（CSV / TSV / Excel）

> 定位是**简单顺手地看和改**：常用的都做了，样式编辑、图表、透视表这类重活仍然交给 Office / WPS。

**打开就能用**
- **格式支持**：`.csv / .tsv` 走文本管线（按编码保存、可编辑）；`.xlsx` 可读写；`.xls / .xlsb / .ods` 只读查看
- **大文件流畅**：CSV 采用「只扫行偏移、按需解析行」的惰性索引（十几 MB / 十几万行无压力、没有行数上限）；Excel 按行窗口按需加载 + 虚拟滚动，百万行级也不卡
- **企业加密文档**：亿赛通等透明加密的 Excel / CSV 会在**内存中解密**后查看与编辑，写回时重新加密，**不产生明文临时文件**；打不开时明确告知原因（需要密码、旧版格式、假 Excel 等）
- **不劫持文件关联**：不会抢占 `.xlsx / .docx` 的默认打开程序，随时可以用回 Office / WPS

**看与定位**
- **区域选择与实时统计**：拖动框选、`Shift+点击` / `Shift+方向键` 扩展、点列标头选整列、点行号栏选整行、`Ctrl+A` 全选；底部实时显示 **求和 / 平均 / 数值个数 / 最小值 / 最大值**（选区超出一屏时由后端精确统计，十几万行也算得准）
- **冻结窗格**：不冻结 / 冻结首行 / 冻结首列 / 冻结首行和首列，滚动时固定不动并有分隔线，首列上方保留列标与列宽拖拽
- **自动调整**：按内容自动调整**列宽 / 行高 / 两者**；另有「**自动换行并调整行高**」一键搞定长文本
- **手动调整宽高**：拖列标头边界改列宽、拖行号栏边界改行高，**双击边界**按内容自动调整；手动值优先，且调整本身也能 `Ctrl+Z`
- **自动换行**：长文本只在**本单元格内部**折行，行高按真实折行数自动变高（按字体逐字测量取上界，宽字形西文也不会被裁）

**查找与替换**
- **浮动查找面板**（`Ctrl+F` 打开、`Ctrl+H` 展开替换行）：**区分大小写 / 全字匹配 / 正则 / 循环查找**、命中计数、上一个/下一个、**替换 / 全部替换**，范围可选**整表或当前选区**
- 命中用**浅琥珀底色**提示，**当前命中**更深并带高对比描边；**选区高亮始终保留**，跳转只滚动、不动选区与焦点框
- 已知限制（面板上有说明）：**替换只作用于当前工作表**；**Excel 不支持正则**（会置灰并说明）

**改内容**
- **单元格编辑**：双击进入（`F2` / 直接输入也行），`Enter` 下移、`Tab` 右移、`Esc` 取消；内容栏（公式栏）左侧提供 **`✕` 取消 / `✓` 接受 / `fx` 插入公式** 三个按钮
- **复制粘贴清空**：`Ctrl+C` 复制成制表符文本（可直接粘进 Excel / WPS），`Ctrl+V` 粘贴一块数据（自动识别文本 / 数字 / 日期），`Delete` 清空选区
- **拖拽自动填充（Excel 填充柄）**：选中几格后拖右下角小方块，按规律自动填充 —— 数字等差（`1 3 5` → `7 9 11`）、带尾号文本（`第1项` → `第2项`、`A01` → `A02` 保留补零）、**公式相对引用自动平移**（`=B2*C2` → `=B3*C3`）、其它内容循环复制；拖到边缘会**自动滚动**，一次能填几百行
- **行列与工作表结构**：插入 / 删除行列、新建 / 重命名 / 删除 / 复制工作表（CSV 同样支持插入删除行列，保留原换行符风格与引号字段）
- **公式能算**：输入 `=SUM(E1:E2)` 直接显示结果（单元格显示结果、内容栏显示公式原文）。支持 `+ - * / ^ %`、比较、括号、`&`，25 个常用函数，引用支持 `A1`、`$A$1`、`A1:B2`、**整列 `B:B`**、整行 `2:2`、跨表 `第二表!A1`；范围内出错会**指出位置**（`#DIV/0!（A2 出错）`）
- **公式补全**：输入 `=` 提示 80 个常用函数（带用法签名）；`=SUM(B` 直接给出 `B:B`（整列）与 `B2:B333`；工具栏「插入公式」可用**当前选区**一键插入 `=SUM(B2:B10)` 等常用公式
- **像 Excel 一样用鼠标选范围**：编辑公式时直接在表格上拖选即可写进公式（光标前已有引用会**被替换**）；选中含公式的单元格会显示引用范围的**虚线框**

**保存与撤销**
- **延迟写回**：所有改动先留在内存里并标记「未保存」，**按 `Ctrl+S` 才写回文件**；保存走「临时文件 → 校验可读 → 原子替换」，中途失败原文件不受影响，默认不生成 `.bak`（可在设置里开启）
- **撤销覆盖一切，保存也不影响**：单元格编辑、清空、粘贴、拖拽填充、插入删除行列、工作表增删改复制、**列宽行高调整**全部进同一条撤销栈；结构操作删掉的行**连同内容**能撤回来；`Ctrl+S` 之后仍可一路 `Ctrl+Z`（撤销后重新变"未保存"）；一次拖拽填充 / 一次拖动调整宽高都**只占一个撤销步**
- **一眼看出改过哪些格**：有未保存改动的单元格右上角有小三角，保存后消失

### 🧭 代码智能阅读与导览（Code Viewer & Navigation）
- **多语言符号引擎**：内置 Rust、TypeScript / JavaScript、Python、Go、C / C++、Java、C# 等主流语言的函数、类、结构体、接口与方法解析
- **跳转到定义（`F12` / `Ctrl+左键`）**：在任意函数或类型引用处一键定位至原定义位置，支持跨文件工作区检索
- **速览原函数实现（`Alt+F12`）**：无需离开当前上下文，内联弹窗**精准提取并仅展示目标函数体**，配备独立滚动条，支持一键在左/右分栏并排打开
- **查找所有引用（`Shift+F12`）**：汇总展示符号在当前文件及工作区内的所有定义与调用位置，点击即可预览或跳转
- **顶部符号面包屑导航栏**：实时显示 `文件路径 › 所属类/模块 › 当前函数`，点击可下拉快速切换同文件任意函数
- **分栏独立导航历史栈**：左/右分栏各自独立维护「返回上一位置（`Alt+←`）/ 前进下一位置（`Alt+→`）」，跨栏打开函数绝不污染原分栏历史或引发焦点乱跳

### 📑 PDF 深度阅读与无损批注
- **划词高亮与批注合一**：选中文字即可添加多色高亮（自动合并同行分片消除重叠色块）、支持右键随时切换高亮颜色，或直接附加文字批注
- **自由便签卡片**：页面任意位置插入便签，智能避让防遮挡，支持随时拖拽移动与编辑
- **全层级书签大纲 + 批注侧栏**：完整解析媲美 Adobe Acrobat 的多级嵌套书签树；侧栏集中聚合所有高亮、批注与便签，点击直达对应页码与位置
- **无损持久化与污染修复**：批注独立保存并支持写回 PDF 标准注释层；内置历史受污染 PDF 物理高亮深度剥离与还原能力
- **全操作撤销与重做**：高亮、换色、批注、便签、页面顺/逆时针旋转均支持 `Ctrl+Z` / `Ctrl+Y` 多步撤回

### 🪟 真·双栏独立对照工作区
- **左右双栏自由组合**：支持左看 PDF 文献、右写 Markdown 笔记，或左看函数调用处、右看原函数实现（支持同一文档在左右两栏同时打开不同位置）
- **智能分栏右键菜单**：根据标签当前所在栏位动态切换「在右侧分栏打开 / 在左侧分栏打开」
- **窗口分栏独立缩放**：按住 `Ctrl + 鼠标滚轮` 仅放大/缩小当前鼠标所在分栏的文档（编辑区、预览区、PDF 均按分栏独立记忆缩放比例），绝不干扰另一栏

### ♿ 无障碍体验（红绿色弱友好模式）
- 在 **设置（`Ctrl+,`）→ 外观与无障碍** 中一键开启 **「色弱友好模式（红绿色弱优化）」**：
  - **Okabe-Ito 国际通用无障碍代码高亮**：彻底避开易混淆的红-绿/橙-绿对比，采用**洋红紫关键字（配半粗体双重线索）**、**天青蓝字符串**、**暖琥珀金数字/常量**、**波浪下划线错误提示**
  - **PDF 高亮「色彩 + 底部线型」双重编码**：将三色高亮升级为高对比度的 **明黄（实线底边）/ 天青蓝（虚线底边）/ 洋红紫（双线底边）**，工具栏、右键菜单与侧栏同步显示无障碍色名与线型标识
  - **带中文色名的主题强调色**：设置面板强调色选择器采用「色点 + 中文色名胶囊按钮」，无需仅凭裸眼辨色

### 📖 Markdown 阅读与 ✍️ 顺手编辑
- **GFM 与扩展语法全支持**：表格、任务列表、提示块 `> [!NOTE]`、高亮 `==文字==`、下划线 `++文字++`、上下标、YAML Front Matter 元数据卡片
- **公式与图表按需加载**：KaTeX 数学公式、Mermaid 流程图/时序图/状态图按需延迟加载
- **三视图无缝切换**：预览 / 源码 / 分屏（`Ctrl+E` 一键循环），分屏双向滚动精准同步
- **多标签页 + 会话自动恢复**：意外关闭不丢草稿，启动自动还原上次打开的 Markdown、代码、PDF 与表格文档及阅读位置

### 📤 四格式一键导出

## 技术栈

<div align="center">

**Tauri 2** · **Rust** · **React 19** · **TypeScript** · **Vite** · **TailwindCSS 4** · **CodeMirror 6** · **PDF.js** · **calamine** · **umya-spreadsheet** · **markdown-it** · **highlight.js** · **DOMPurify**

</div>

- **前后端分离**：文件读写、目录扫描、文件监听、表格解析与写回、PDF 原生清理、安全下载与打印走 Rust；界面、编辑器与多格式渲染走 WebView2
- **极致体积**：KaTeX / Mermaid / PDF 引擎 / 代码语言包全部通过 Vite 代码分割按需加载
- **安全优先**：`html: false` + DOMPurify 双重净化，外部链接交由系统默认浏览器安全打开

## 开发与构建

```bash
# 环境要求：Node ≥ 20、pnpm ≥ 9、Rust stable ≥ 1.77、VS Build Tools 2022
pnpm install
pnpm tauri dev        # 开发运行
pnpm typecheck        # TypeScript 类型检查（提交前必过）
pnpm build            # 仅构建前端
pnpm tauri build      # 打包 EXE 与 NSIS 安装包
cd src-tauri && cargo test --lib   # Rust 单元测试（表格解析 / 公式求值等）
```

国内网络可先设置代理：

```powershell
$env:HTTP_PROXY="http://127.0.0.1:7890"; $env:HTTPS_PROXY="http://127.0.0.1:7890"
```

发布（单点上传海外节点，国内阿里云节点每 5 分钟自动同步）：

```powershell
.\tools\publish.ps1 -Mode installer -Build -NotesFile "tools\notes-<版本>.txt"   # 软件中心
python tools\publish-github-release.py                                            # GitHub Release
```

```text
├── stores/            Zustand：文档与分栏状态、设置持久化、搜索、弹窗、在线更新

├── lib.rs             插件注册、单实例唤醒、窗口关闭拦截、启动参数解析

```
