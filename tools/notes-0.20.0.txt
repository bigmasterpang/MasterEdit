### MasterEdit v0.20.0 更新日志

本次更新集中重做了**办公表格（xlsx / CSV）**的查看与编辑体验。

#### 一、查看与定位

1. **区域选择与统计**：拖动框选、`Shift+点击` / `Shift+方向键` 扩展、点列标头选整列、点行号栏选整行、`Ctrl+A` 全选；底部实时显示 **求和 / 平均 / 数值个数 / 最小值 / 最大值**（选区超出一屏时由后端精确统计，十几万行也算得准）。
2. **冻结窗格**：工具栏「冻结」下拉可选 **不冻结 / 冻结首行 / 冻结首列 / 冻结首行和首列**（支持多行多列）。冻结区在滚动时固定不动、有不透明底色、与滚动区之间有分隔线，首列上方保留列标与列宽拖拽。
3. **自动调整列宽 / 行高**：工具栏「自动调整」下拉可选 **列宽 / 行高 / 两者都调整**（右键菜单也有单项）。列宽按内容计算（中文按 2 字符宽，56~480px），行高按真实折行数计算。
4. **自动换行**：右键菜单开关。长文本**只在本单元格内部折行**，行高按折行数自动变高（折行行数按真实字体逐字测量并取上界，宽字形西文也不会被裁）；行号栏每行一个标签，不重叠不漂移。
5. **手动调整宽高**：拖列标头边界改列宽、拖行号栏边界改行高；**双击边界**按内容自动调整；手动值优先于自动调整。
6. **查找替换面板**（参考 Markdown 的查找）：浮动面板，`Ctrl+F` 打开、`Ctrl+H` 展开替换行；支持 **`Aa` 区分大小写 / `W` 全字匹配 / `.*` 正则 / 循环查找**、命中计数、上一个/下一个、**替换 / 全部替换**，范围可选**整表或当前选区**。命中会**自动滚动到该行**并高亮，跨工作表命中自动切表定位。
    - 已知限制（面板上有提示）：**替换只作用于当前工作表**；**xlsx 不支持正则**（会置灰并说明）。

#### 二、编辑

7. **单元格编辑**：双击进入编辑，`Enter` / `Tab` 提交并移动，`Esc` 取消；内容栏（公式栏）左侧提供 **`✕` 取消 / `✓` 接受 / `fx` 插入公式** 三个按钮（与 Excel 一致）。
8. **复制、粘贴、清空**：`Ctrl+C` 把选区复制成制表符文本（可直接粘进 Excel / WPS），`Ctrl+V` 粘贴一块数据（自动识别文本 / 数字 / 日期），`Delete` 清空选区。
9. **右键菜单**：复制 / 粘贴 / 清空 / 自动调整列宽 / 自动调整行高 / 自动换行 / 撤销 / 重做 / 插入删除行列；在选区外右键会先把选区移到该格（与 Excel 一致）。
10. **结构操作（插入删除行列、工作表增删改复制）**：只改内存中的工作簿副本，界面立刻生效并标记「结构已修改（未保存）」，**按 `Ctrl+S` 才写回文件**；不再弹确认框（删错了 `Ctrl+Z` 即可），也不再生成 `.bak` 备份（保存直接写回原文件：临时文件 → 校验可读 → 原子替换，中途失败原文件不受影响）。
11. **撤销重做覆盖所有操作，保存也不影响**：单元格编辑、清空、粘贴、插入删除行列、工作表增删改复制、**列宽行高调整**全部进同一条撤销栈；结构操作删掉的行**连同内容**能撤回来；`Ctrl+S` 之后仍可一路 `Ctrl+Z`（撤销后重新变"未保存"）；拖动调整宽高**只产生一个撤销步**。

#### 三、公式

12. **公式能算了**：输入 `=SUM(E1:E2)` 回车**直接显示计算结果**（单元格显示结果、内容栏显示公式原文，与 Excel 一致）。支持 `+ - * / ^ %`、比较、括号、`&`，25 个常用函数（SUM / AVERAGE / COUNT / COUNTA / MIN / MAX / ABS / ROUND / INT / IF / IFERROR / AND / OR / NOT / LEN / LEFT / RIGHT / MID / TRIM / UPPER / LOWER / CONCAT / TODAY / NOW），引用支持 `A1`、`$A$1`、`A1:B2`、**整列 `B:B`**、整行 `2:2`、跨表 `第二表!A1`。
    - **范围内出错会明确报错并指出位置**：区域里某格是 `#DIV/0!` → 显示 `#DIV/0!（A2 出错）`；用了不支持的函数 → `暂不支持函数 VLOOKUP（A2）`；多处出错取先行后列第一个；嵌套引用保留根因位置；普通文本仍按 Excel 语义忽略；`=IFERROR(SUM(A1:A3),"x")` 能捕获。
    - 打开旧文件时里面的公式会重算显示（而不是显示 0）；结果只用于界面显示，文件里仍只写公式，Excel / WPS 打开时自己重算。
13. **公式补全与区域引用**：输入 `=` 提示 **80 个常用函数**（带用法签名与中文说明）；`=SUM(B` 直接给出 **`B:B`（整列）**、`B2:B333`；`=SUM(2` 给出 `2:2`；工具栏「插入公式」下拉可用**当前选区**一键插入 `=SUM(B2:B10)` 等 9 种常用公式。
14. **像 Excel 一样用鼠标选范围**：编辑公式时直接在表格上拖选即可把 `B3:B4` 写进公式（编辑框不失焦），光标前已有引用会**被替换**（`=SUM(B3:B4)` 拖一下改成 `=SUM(C1:C2)`）；选中含公式的单元格会显示引用范围的**虚线框**。

#### 四、其他

15. **CSV 默认就能编辑**：CSV / TSV 的自动只读阈值放宽到 64MB（表格视图按需解析行，十几万行照样流畅）；任何只读文档都可以点状态栏的「只读 · 点击可编辑」随时切换。
16. **界面细节**：表格文档状态栏不再显示「原始字数 / 预览字数 / 词数」，改为文件大小、格式、是否可编辑与未保存状态；编辑单元格不再出现重复的两圈高亮；只读文档点单元格不再出现多余的焦点框；表格没有变化时按 `Ctrl+S` 不再弹提示。
