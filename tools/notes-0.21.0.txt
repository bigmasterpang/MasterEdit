### MasterEdit v0.21.0 更新日志

**新增：Word 文档（.docx）只读查看**

MasterEdit 现在可以直接打开 `.docx` 阅读 —— 排版忠实还原，**企业加密文档自动解密**，需要编辑时一键交给 Word / WPS。

#### 打开即看

- **自动解密**：亿赛通等透明加密的 Word 文档会在**内存中解密**后查看，不会写出明文副本
- **排版还原**：段落字体字号颜色、粗体斜体下划线删除线、上下标、对齐、左右缩进与首行/悬挂缩进、段前段后、行距（倍数与固定值）
- **多级编号**：`一、` / `1、` / `（1）` / `•` 等各级编号与项目符号按原文档还原（中文数字、罗马数字、带圈数字等都支持）
- **表格**：横向合并（跨列）与纵向合并（跨行）都能正确还原，含列宽、边框、底纹、表头行、单元格内多段落与嵌套表格
- **图片**：按原尺寸显示，滚动到可见才加载
- **分页提示线**：不强行分页，但在原分页位置画一条淡色提示线（知道原来分在哪，又不必自己排版）
- **大纲侧栏**：按文档自身的标题级别生成目录，点击跳转
- **查找**：`Ctrl+F` 搜索全文，命中自动滚动到位置并高亮，`F3` / `Shift+F3` 上下一个
- **缩放**：工具条按钮或 `Ctrl+滚轮`

#### 复制（编辑需求交给外部应用）

- 正文**可以直接选中复制**；工具条提供 **「复制全部文本」**
- 表格右键 → **「复制为制表符文本」**，可直接粘进 Excel / WPS
- 图片与暂不支持的对象在复制文本里会以 `[图片：说明]`、`[公式]` 等标注，**不会静默丢内容**

#### 需要编辑时

- 工具条 **「用其它应用编辑」** / **「选择打开方式…」** —— 交给系统里的 Word / WPS（加密文档由系统驱动透明解密）
- 工具栏「打开方式」下拉对**所有**文档类型都可用（Excel / CSV / PDF / Markdown 同样适用）

#### 暂不支持（界面上会明确标注，不会静默丢失）

- SmartArt 图形、图表、OLE 嵌入对象、文本框、数学公式（OMML）：显示为**占位卡片 + 中文说明**（公式会把纯文本回显出来）
- EMF / WMF 矢量图：显示占位说明（浏览器无法直接渲染）
- 修订痕迹按**最终态**显示（不提供接受/拒绝）
- Word 97-2003 的 `.doc` 老格式：会提示「请用 Word / WPS 另存为 .docx」
- **不支持编辑**（本版本定位是查看；编辑请用「打开方式」交给外部应用）

#### 实测规模

用 25 个真实加密周报（13.2 MB，最大单篇 4.8 MB）做了完备性验证：**全部解析成功、零失败零崩溃**，`document.xml` 全部结构良构；真实文档里最大的一篇（184 段落 + 3 表格 + 7 图片）滚动流畅。
