### MasterEdit v0.18.0 更新日志

1. **新增 CSV / TSV 表格视图**：打开 CSV 直接看到表格，自动识别逗号 / 分号 / 制表符分隔符，兼容引号字段、字段内换行与 BOM；`Ctrl+E` 在「表格 / 源码 / 表格 + 源码」之间切换，需要改数据时切到源码即可编辑保存。

2. **新增 Excel 只读查看（xlsx / xls / xlsb / ods）**：内置 Rust 解析引擎（calamine），打开即看；支持多工作表标签、列标与行号和 Excel 完全对齐、单元格内容与公式栏、百万行级虚拟滚动不卡顿。

3. **支持企业加密（亿赛通等）的 Excel / CSV**：透明加密的工作簿会在**内存中**解密后解析，不产生明文临时文件；标题栏与状态栏显示「已解密」标记。同时把「打不开」的原因说清楚：需要密码的 Office 文档、旧版二进制格式、系统导出的假 Excel（真实内容是 HTML 表格）现在都会给出可执行的提示。

4. **超大 CSV 完整可见**：表格视图改为「只扫描行偏移、按需解析行」的惰性索引，不再有 2 万行上限 —— 十几 MB、十几万行的 CSV 也能从头滚到尾，内存占用反而更低。

5. **滚动更跟手**：滚动位置按帧合并渲染、扩大预渲染缓冲区，未渲染区域显示为淡色网格线而不是白屏，快速拖动滚动条不再出现「先白屏再出数据」。

6. **会话恢复更可靠**：修掉了「大 CSV 关闭软件后不再恢复」的问题（体积大的干净文档现在会按路径恢复，超大文件以只读方式恢复）；应用退出时会立即补写一次会话，刚打开的标签页不会因为写入防抖而丢失。

7. **表格安全只读**：Excel / ODS 文档绝不写回原文件，避免格式被破坏；需要编辑时右键「用系统默认程序打开」交给 Excel / WPS，CSV / TSV 则可直接在源码模式编辑保存。

8. **不抢占文件关联**：安装包不会把 `.xlsx` / `.docx` 注册为系统默认打开程序，双击仍由 Office / WPS 处理，随时可以改回来。
